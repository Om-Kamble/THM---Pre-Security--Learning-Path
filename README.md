# 🛡️ TryHackMe Pre Security — Learning Path

## 📌 About This Repository

Welcome to my **TryHackMe Pre Security Learning Journey**!

This repository documents my hands-on learning experience as I work through the Pre Security Learning Path on TryHackMe. After completing the SOC Level 1 path, I am going back to the fundamentals to strengthen my foundation in how computers, operating systems, networks, and the web actually work, because to attack or defend any technology, you first need to understand what powers it.

I created this repository to track my learning journey, consolidate my technical knowledge, document important concepts, and build a professional cybersecurity portfolio.

## 🗺️ Learning Path

**Platform:** [TryHackMe](https://tryhackme.com/)

**Learning Path:** [Pre Security](https://tryhackme.com/path/outline/presecurity)

**Difficulty:** Easy (no prior experience required)

**Path Size:** 7 modules, 31 hands-on labs, approximately 19 hours

**Focus Area:** Cyber security foundations: computing, operating systems, networking, and the web

**Current Status:** In Progress

**Primary Goal:** Build a strong technical foundation across computers, operating systems, programming basics, networking, and web technologies before moving into advanced security topics.

### 📋 Modules and Rooms

| # | Module | Rooms |
| - | ------ | ----- |
| 1 | Introduction to Cyber Security | Offensive Security Intro, Defensive Security Intro, Careers in Cyber |
| 2 | Computer Fundamentals | Inside a Computer System, Computer Types, Client-Server Basics, Virtualisation Basics, Cloud Computing Fundamentals |
| 3 | Operating Systems Basics | Operating Systems: Introduction, Windows Basics, Linux CLI Basics, Windows CLI Basics, Operating System Security |
| 4 | Software Basics | Data Representation, Data Encoding, Python: Simple Demo, JavaScript: Simple Demo, Database SQL Basics |
| 5 | Network Fundamentals | What is Networking?, Intro to LAN, OSI Model, Packets & Frames, Extending Your Network |
| 6 | How The Web Works | DNS in Detail, HTTP in Detail, How Websites Work, Putting it all together |
| 7 | Attacks and Defenses | The CIA Triad, Cryptography Concepts, Become a Hacker, Become a Defender |

## 📚 What I Document

For each completed room or module, I aim to record:

* **Room Overview:** The main topic and learning objectives.
* **Key Concepts:** Important concepts explained in my own words.
* **Tools Used:** Platforms, terminals, and environments explored during practical exercises.
* **Commands and Syntax:** Useful Linux, Windows, Python, JavaScript, and SQL examples learned during exercises.
* **Diagrams and Mental Models:** Visual explanations of topics like the OSI model, DNS resolution, and the HTTP request/response cycle.
* **Practical Exercises:** My approach to lab tasks and how they connect to real-world scenarios.
* **Challenges and Mistakes:** Problems I ran into and how I worked through them.
* **Key Takeaways:** Important lessons and their relevance to security.
* **Screenshots:** Relevant evidence of my practical work, where permitted by TryHackMe.

My focus is on understanding the concepts rather than simply completing rooms.
